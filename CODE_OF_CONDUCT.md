# Code of conduct

Cicada follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent and keep discussions about the work. Harassment and personal attacks are not accepted.

To report unacceptable behavior, contact the maintainer [@sultanjakhan](https://github.com/sultanjakhan) on GitHub. Reports are kept confidential.
