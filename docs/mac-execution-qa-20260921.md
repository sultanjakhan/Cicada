## Расхождение перехода «Вернуться»

Воспроизведение: начать Alpha → пауза → начать Beta → пауза → перезапустить
приложение → нажать «Вернуться: QA Alpha».

Критерий #93 предусматривает прежнее действие и «Продолжить», без автоматического
запуска после возвращения. Фактически нажатие «Вернуться» сразу запускает Alpha;
само открытие приложения таймер не запускает. Время после нажатия начинает
учитываться как работа до отдельного действия пользователя.

В `src/hanni/js/calendar-now.js` ветка `return` явно вызывает
`startCalendarExecution`. Тест `return keeps the previous task across restart
without starting it automatically` в `tests/upstream-calendar-now.test.mjs`
проверяет отсутствие старта при remount, но ожидает `active` после «Вернуться».
Существующие тесты тем самым закрепляют наблюдаемое поведение. Критерий и
реализация расходятся; решение и дальнейшая работа остаются в исходной задаче
#93, без изменения её статуса этим отчётом.
