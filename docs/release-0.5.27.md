# Cicada 0.5.27

Task filter reset now clears the visible Source, Project and Tag selectors along
with the applied filters. Choosing another filter after reset no longer leaves
an old project name displayed beside the results.

This release includes the unfinished-task views from 0.5.26: All contains active
and not-started work; Completed and Archive retain separate histories. Existing
tasks, goals, results and recorded time are preserved.
