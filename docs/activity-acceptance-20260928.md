## Поведение

Настройки → Ограничения содержит локальные подключения Windows/Android,
ручной импорт, автоимпорт, паузу, изменение и удаление подключения. На один
день и подключение создаётся обычное событие существующего календаря без часа.
Детали показывают время по приложениям. Новая вкладка календаря не добавлена.

ActivityWatch хранит исходные интервалы. Cicada получает их через loopback,
отвергает данные с заголовками окон/URL и сохраняет дневные агрегаты.
Ключ API хранится отдельно от календаря; настройки соединения не синхронизируются.
Ручной импорт разрешён на паузе. Остановка импорта не останавливает сборщик.

В существующем редакторе рутины для одного дела без таймера доступна короткая
рефлексия. Ответы по дням сохраняются отдельно от отметки выполнения. Нет ответа
не считается соблюдением или нарушением. Личный вопрос не включён в поставку.

Раздел блокировщиков пока показывает проверенные точки входа в сторонние
инструменты. Он не выдаёт сохранённое пожелание за действующее ограничение.

## Условия выпуска и продолжения

1. **Существенно: совместимость синхронизации.** Старый клиент воспроизводимо
   удаляет новые ответы при отметке дня, а вопрос — при редактировании рутины.
   Все связанные клиенты, включая offline, должны получить совместимый артефакт
   перед использованием этой функции в общем профиле. Затем проверить физический
   двусторонний round-trip после отметки и переименования. Автоматического барьера нет.
2. Телефон во время финальной интеграционной проверки уже отключён от USB.
   Его ранее проверенный сборщик не заменяет проверку «телефон → эта Cicada».
   Mac, второй Android и iPad не настроены. Для Mac нет принятого коннектора;
   Windows-настройка скрытия заголовков не доказывает приватность Mac.
3. Системные ограничения пока не действуют. TimeLimit установлен отдельно;
   правила не настроены. LeechBlock NG остаётся кандидатом. У Focuser v0.8.0
   CLI использует `NoopSync`, поэтому успешная команда не доказывает блокировку;
   этот путь управления не принят.
4. Agent City хранит каталог. Три карточки связаны с Cicada; отдельная ветка
   `work/app-catalog-20260927-91e4`, коммит `3d9b508827641bb43e69aab4164dab5f8060585e`,
   добавляет Codeberg/GitLab в валидатор (9 тестов). В рабочий сервер патч не
   переносился: его checkout принадлежит другой работе. Карточка TimeLimit с
   правильным Codeberg URL ждёт этого переноса.
