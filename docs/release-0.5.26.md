# Cicada 0.5.26

The Tasks pane opens with **All**, showing unfinished tasks, including those not
started. **Active** shows tasks with recorded execution, including paused work
and work awaiting review. **Not started** is available inside **Filters**.

**Completed** contains finished work. **Archive** contains tasks removed from the
working list and retains their completion state and history for restoration.
The navigation includes short descriptions of these states.

Native task lists expose their saved tags, so project and tag selectors can
filter the existing tasks. Goal, project and tag choices remain inside Filters.
Task identities, recorded time, results and review decisions are preserved.
